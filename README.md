# Cap Canada V3 — Journalisme sportif au Canada

## Nouveautés V3
- Annuaire des médias conservé depuis la V2.
- Espace dossier et suivi des candidatures conservés.
- Nouvelle rubrique de réseautage LinkedIn avec profils publics repérés, filtres par nom/média/langue et liens directs.
- Raccourcis de recherche LinkedIn pour trouver d'autres journalistes par média.

## Installation
1. Décompresser `cap-canada-v3.zip`.
2. Ouvrir `index.html` dans un navigateur pour tester.
3. Pour publier : déposer `index.html` dans un dépôt GitHub et activer GitHub Pages.

## Limites et vérification
- Les liens pointent vers des profils LinkedIn publics trouvés lors d'une recherche web le 5 novembre 2026.
- L'affiliation et le poste peuvent changer : vérifier la page avant toute prise de contact.
- Les personnes listées ne sont pas présentées comme recruteurs ou responsables RH.
- Le site ne se connecte pas à LinkedIn et ne récupère pas automatiquement les données de la plateforme.
- Les données personnelles et le suivi de candidature restent stockés localement dans le navigateur (localStorage). Exporter régulièrement la sauvegarde JSON.
- Les candidatures ne sont pas envoyées automatiquement.
